The Robot Sandwich Problem

🤖 You need to teach a robot — that can only follow very specific step-by-step instructions — how to make a Vegemite sandwich.

The robot knows nothing. It cannot guess, assume, or use common sense. What instructions would you give it?

Discuss with your partner — click each question to reveal a thinking hint:

Q1
What information does the robot need before it can start?
💡 Think: ingredients, tools, location of objects. What if the bread is in the cupboard?
Q2
What happens if you skip a step or put steps in the wrong order?
💡 Try spreading Vegemite before opening the jar — the algorithm fails! Order matters.
Q3
Does the order of the steps matter? Why?
💡 Yes — algorithms are sequential by nature. The robot cannot anticipate future steps.
Q4
Can two people write different instructions and both be 'correct'?
💡 Yes! There is rarely only ONE correct algorithm. Different approaches can all solve the same problem.
New Learning · K1

Control Structures

Every algorithm — and every program — is built from just three fundamental control structures. Click each tab to explore them.

SEQUENCE
Steps are executed one after another, in a fixed order. Every program has sequence — it's the default flow of execution.

Think of a recipe: you can't eat the cake before you bake it, and you can't bake it before you mix the ingredients.

# Making a cup of tea — pure sequence boil_kettle() place_teabag("mug") pour_water(200, "mL") wait(3, "minutes") remove_teabag() add_milk() # optional!

⚠ Swap any two lines and the algorithm breaks. Try it mentally — what happens if you pour water before placing the teabag?

END

SELECTION
The algorithm makes a decision and follows different paths depending on whether a condition is True or False.

Also called IF–THEN–ELSE. Selection lets programs respond differently to different situations or data.

# Simple selection if is_raining: take_umbrella() else: leave_umbrella_home() # Nested selection (selection inside selection) if score >= 90: grade = "A" elif score >= 75: grade = "B" else: grade = "C"

Flowchart

START
↓
Is it raining?
↓
YES ↓
Take umbrella
NO ↓
Leave umbrella
↓
END

ITERATION
A block of steps is repeated — either a fixed number of times (for loop) or until a condition is met (while loop).

Iteration makes code efficient — instead of writing the same steps 100 times, you write them once inside a loop.

# FOR loop — counted repetition for card in range(5): deal_card(player) # WHILE loop — conditional repetition while battery > 0: play_music() battery -= 1 print("Battery dead!")

⚠ A while loop that never becomes False runs forever — this is called an infinite loop and is a common bug!

↓

↓

YES ↓

↑ loop back
NO ↓
END
Dive In · Algorithms in Real Life

Can you spot the control structures?

🌅 Morning Routine
Sequence Selection Iteration 
START
  SEQ: Wake up → turn off alarm
  SEL: IF school day THEN get dressed
         ELSE stay in pyjamas
  ITR: WHILE not full: eat breakfast
  SEQ: Pack bag → leave house
END
🚦 Traffic Lights
Sequence Selection Iteration 
START
  ITR: WHILE intersection is active:
    SEQ: RED(60s) → GREEN(45s) → AMBER(5s)
    SEL: IF pedestrian button pressed:
               show WALK signal
END
📺 Streaming Service
Sequence Selection Iteration 
START
  ITR: WHILE watching:
    SEQ: Play episode → show credits
    SEL: IF no input after 5s:
               auto-play next episode
END
🎮 Video Game Enemy
Sequence Selection Iteration 
START
  ITR: WHILE enemy health > 0:
    SEL: IF player nearby:
               attack player
         ELSE:
    SEQ:       patrol → scan → move
END

Check for Understanding · Quiz

Quick Quiz

Q1. An algorithm must eventually stop. What characteristic does this describe?

Correct! "Finite" means the algorithm must end. An algorithm that runs forever produces no useful result.

Q2. Which control structure does this code use?
for i in range(5): print(i)

Correct! for loops are iteration — they repeat a block of code a fixed number of times.

Q3. A GPS app says: "IF traffic detected THEN take alternate route ELSE continue on current road." What control structure is this?

Correct! The IF–THEN–ELSE structure is Selection. The GPS decides which path to take based on a condition.

Q4. You are designing an algorithm to find the highest score in a list of 100 game scores. Which control structure is most essential?

Correct! You need a loop to visit each of the 100 scores. You'd also use selection inside the loop (IF score > current_max) — algorithms often combine all three structures!

Q5. True or False: There is always exactly ONE correct algorithm for any given problem.

Correct! This is a key insight! Many algorithms can solve the same problem. Some are faster, some use less memory, some are easier to read. That's why computer scientists compare algorithms.
